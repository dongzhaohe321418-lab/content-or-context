\section{Related work}
\label{sec:related}

\paragraph{Model stitching and representational similarity.}
Stitching joins the lower layers of one network to the upper layers of another through a trainable layer, and has long been used to ask whether two networks compute compatible representations \citep{lenc2015equivariance,bansal2021stitching}. \citet{chen2025stitching} showed that affine maps between the residual streams of language models in the same family (Pythia, GPT-2, Gemma-2), fitted on OpenWebText, transfer features, probes and steering vectors. The platonic representation hypothesis \citep{huh2024platonic} and unsupervised embedding translation \citep{jha2025vec2vec} suggest that related maps exist more generally, but neither establishes the residual-stream maps needed here. We ask whether a stitch fitted without reading any corpus text improves a receiver's predictions using content it otherwise lacks.

\paragraph{Weight-only alignment.}
Relative representations \citep{moschella2023relative} compare independently trained latent spaces through similarities to shared anchor inputs, so they still require inputs. Permutation matching \citep{ainsworth2023rebasin} aligns networks from their weights alone but requires identical architectures. LatentMAS \citep{zou2025latentmas} maps a model's output hidden states back to its own input-embedding space with a least-squares map between the output and input embedding matrices, a training-free alignment derived from one model's weights. Our weight-only baseline applies the same idea across two models, using their stacked embedding and unembedding matrices.

\paragraph{Latent communication between language models.}
Several systems let language models exchange hidden states or key--value caches instead of text. Cache-to-Cache fuses one model's KV cache into another's through a learned fuser, trained on general instruction data in its main experiments \citep{fu2026c2c}. LatentMAS shares last-layer states and KV caches among agents built on the same backbone, without training \citep{zou2025latentmas}. Interlat uses a trained adapter to insert a sender's last-layer states into the receiver's input-embedding sequence, including across model families, and its training objective already contrasts matched messages with messages from a different task in the same batch. It also notes that maximising this separation can harm task utility, and adds a regulariser that aligns the receiver's predictions with those under a language-space plan \citep{du2025interlat}. We use the matched-versus-swapped contrast for \emph{evaluation} rather than training, and the same concern applies there: the contrast must be read next to the net gain over no message (\S\ref{sec:scale}). We also show that the choice of donor matters. A swapped message from the same article still carries much of the target's content, so a valid control must draw donors from other documents (\S\ref{sec:protocol}).
Two concurrent audits use similar controls on latent multi-agent pipelines and reasoning benchmarks. \citet{zhang2026latentchannelsactuallycommunicate} separate the effect that a message generated from a different example retains from the gain attributable to example-specific content. \citet{cheng2026doeslatentcommunicationpay} compare relayed KV caches with the cache of a different example from the same batch, and with zeroed and random caches, and find that a large cache effect need not depend on pairing. Their donors are independent benchmark items. Our setting adds contiguous text, where a donor from the same document shares content with the target, and bridges between independently trained models.

\paragraph{Data-free transfer.}
Data-free knowledge distillation synthesises inputs from a trained teacher, for instance by inverting it under batch-norm statistics \citep{yin2020deepinversion}. Our self-sampling baseline is the language-model analogue: the two models generate their own probe text. The LLM-written condition replaces model inversion with an external model's world knowledge. It is motivated by recent evidence that frontier models can read and edit network weights directly \citep{takehi2026sparks}.

\section{Setting and method}
\label{sec:method}

\subsection{Latent bridges}
Let $A$ and $B$ be independently trained causal language models with a shared tokenizer. Write $h^A_\ell(x) \in \mathbb{R}^{n\times d_A}$ for the residual stream of $A$ after layer $\ell$ on an $n$-token input $x$, and similarly for $B$. A \emph{bridge} $f:\mathbb{R}^{d_A}\to\mathbb{R}^{d_B}$ is applied position-wise. It is affine, $f(h)=hM+c$, unless stated otherwise; for the capacity study (\S\ref{sec:diag}) we add a residual MLP branch, $f(h) = hM + c + \mathrm{GELU}\big(\mathrm{LN}(h)W_1 + b_1\big)W_2 + b_2$, with hidden width 2048 and $W_2$ and $b_2$ initialised to zero. $B$ resumes computation at layer $L_B+1$ from the bridged states. All model weights are frozen; only $f$ is trained.

\subsection{Two settings}
\label{sec:protocol}

\paragraph{Hand-over (``full'').}
$B$ receives every position from $A$: $h^B_{L_B} \leftarrow f(h^A_{L_A}(x))$, and we score $B$'s next-token predictions on $x$. This classical stitching test measures how much of a single model's computation survives being split across two networks. It cannot establish that anything was \emph{communicated}, because $B$ could have read $x$ itself.

\paragraph{Information-asymmetric communication (``comm'').}
A window $s$ of $P+S+1$ tokens is split into a prefix $s_{1:P}$ and a suffix. $A$ reads only the prefix. $B$ runs layers $1..L_B$ on the suffix $s_{P+1:P+S}$ alone, producing states $u\in\mathbb{R}^{S\times d_B}$. Position indices are $P+1..P+S$, so the rotary phases match those of the full window. Layers $L_B+1..$ then run on the concatenation $[\,f(h^A_{L_A}(s_{1:P}))\,;\,u\,]$. We score $B$'s predictions of $s_{P+2:P+S+1}$. Because $B$'s lower layers never see the prefix, the message is the only route by which prefix information can reach $B$. We use $P=128$ and $S=32$ throughout.

\paragraph{References and controls.} On identical windows we report:
\begin{itemize}
\item \textbf{No context}: $B$ on the suffix alone.
\item \textbf{Text}: $B$ reading the whole window, \ie{} a channel that forwards the prefix verbatim.
\item \textbf{Receiver-state reference}: $B$'s own layer-$L_B$ states for the prefix, computed by $B$ reading the prefix alone and injected exactly as a bridged message would be. It represents what $B$ itself would send and has not been proved to be an upper bound.
\item \textbf{Donor messages}: window $i$ receives a message from the same source, computed from another window's prefix. The donor comes from a \emph{different article} or \emph{another window of the same article}. Articles are delimited by WikiText's top-level headings, and we use five independent random draws of each kind per window.
\end{itemize}
These give a three-way decomposition of the reduction in $B$'s suffix cross-entropy relative to no context: a \emph{generic} part (no context minus other-article donor), an \emph{article-level} part (other-article minus same-article donor) and a \emph{window-specific} part (same-article donor minus matched message). We call the sum of the last two the \emph{content} gain. As differences in expected log-score, they measure the message's usefulness to this fixed receiver $B$, not mutual information.

\subsection{Fitting bridges without real corpus text}
Every fitted bridge minimises the per-token KL divergence from $B$'s own predictive distribution to $B$'s distribution through the bridge,
\begin{equation}
\mathcal{L}(f) = \mathbb{E}_{s\sim\mathcal{D}_{\text{probe}}}\;\frac{1}{|T|}\sum_{t\in T}\mathrm{KL}\big(p_B(\cdot\mid s_{\le t})\,\big\|\,p_{B\circ f\circ A}(\cdot\mid s_{\le t})\big),
\end{equation}
where $T$ ranges over all positions (\emph{hand-over objective}) or over the suffix positions of the comm setting, with $B$'s full-context distribution as the target (\emph{comm objective}). The objective needs no labels, only probe text on which both models can be run. What differs between conditions is $\mathcal{D}_{\text{probe}}$:
\begin{itemize}
\item \textbf{Real text} (upper reference): windows from WikiText-103 training articles \citep{merity2016wikitext}, the domain of the test set.
\item \textbf{LLM-written text} (synthetic, no real corpus): encyclopedia-style articles written by an LLM (Claude Opus 5.5) with no tools or access to any corpus. The prompt supplied only a style instruction and a topic area, and told the LLM to invent the content. We collected 64 articles (1.03M characters), one per topic area. The main experiments use 24 of them (382k characters, 88k Pythia tokens). Section~\ref{sec:scale} varies the amount.
\item \textbf{Self-samples} (synthetic, from the two models themselves): unconditional samples from $A$ and $B$ themselves at temperature 1.
\item \textbf{Weight-only anchors} (no fitting): $M$ solves $\min_M \lVert [E_A;U_A]M - [E_B;U_B]\rVert_F$ over the token embedding and unembedding matrices, $c=0$. This map also initialises every fitted bridge.
\end{itemize}
LLM-written text is still data: it is synthetic text generated by a teacher model and carries that model's knowledge of language and of the world. What it avoids is real corpus text. Fitting an LLM-written or self-sampled bridge reads no corpus text, and the LLM that wrote the main corpus ran with all tools disabled and no access to files or the network (the second LLM's variant corpus was generated in a read-only sandbox; \S\ref{sec:limitations}). This does not rule out WikiText-like or even WikiText text in the LLM's pretraining; we checked only verbatim overlap with the test and validation splits (Appendix~\ref{app:repro}). Layer selection in the main experiments used real validation text, and \S\ref{sec:where} repeats it with LLM-written text only.

\subsection{Protocol details}
We use final-step Pythia checkpoints \citep{biderman2023pythia}: 70M ($d=512$, 6 layers), 160M ($d=768$, 12 layers) and 410M ($d=1024$, 24 layers). They share a tokenizer and training data but come from separate runs. Bridges are trained with Adam (learning rate $10^{-3}$, batches of 16 windows, 600 steps) on 4096 probe windows of 161 tokens drawn with replacement from the probe text. Self-sampled bridges use 512 generated sequences of the same length, whose 82k tokens are comparable to the 88k tokens of the 382k-character LLM-written text.

Test sets contain 512 non-overlapping windows from the first 6000 lines of the WikiText-103 test split, covering 58 articles. Layer pairs are chosen on the validation split, never on test windows. Because windows from one article are not independent, we use a hierarchical bootstrap (4000 draws) for intervals unless stated otherwise. It resamples whole articles and, within each draw, fitting seeds and donor draws; per-seed estimates are reported alongside. Paired comparisons and per-position or truncation analyses that resample only articles are labelled as conditional on the saved fits and donors. Main-experiment fits use three seeds, which change the probe windows (or samples) and the batch order; diagnostics and layer sweeps use one seed. All runs used one Apple M5 Pro GPU with the Metal backend in float32.
